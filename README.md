# Kuploy Academy — course packages

This repository holds the finished course packages for Kuploy Academy, and nothing else. Each
release is a set of files you can import straight into an Academy, one file per language.

## Get a course

Open [Releases](https://github.com/kuploy/academy-courses/releases) and download the files from
the newest one. No account needed.

The current course is **Kuploy Cloud Training**: eight chapters that take someone from an empty
Kuploy Cloud to a deployed application with its own domain, a certificate and a backup they have
restored themselves. It comes in English and French, as two separate files.

## Put it in your Academy

1. Sign in to your Academy as an administrator.
2. Go to **Courses**, then **Import a course**.
3. Choose one of the downloaded files and confirm.
4. Repeat for the other language, if you want both.

The course arrives with its chapters, its text and its pictures already in place. It is yours
after that: rename it, reorder it, cut a chapter, or put your own words in it.

## When a course changes

A new release appears here. Importing it adds a second copy beside the one you already have — it
does not update the old one. So after you import the new release, unpublish the old copy, and keep
it until you are sure nobody was halfway through it.

## Languages

English and French. The French course is a translation, not a different course: same chapters,
same order, same pictures.
